# Changelog

GlowySilver Epyrus - Changelog
==============================

1.0.0rc1
--------
- First release candidate and final project name: GlowySilver Epyrus.
- Epyrus 2.x complete-theme compatibility based on the cleaned 0.1a28 baseline.
- Dark three-pane interface, secondary dialogs, Preferences, Add-ons Manager,
  Calendar/Today Pane, Address Book, Account Settings and Compose UI.
- Dark Compose editing canvas implemented through Epyrus' editor override
  stylesheet path so display colours are not inserted into outgoing messages.
- Restored original Glowy marble/textured surfaces where appropriate.
- Updated Preferences artwork and added the Epyrus Conversation toolbar icon
  in a matching GlowySilver style.
- Windows titlebar/App Menu compatibility fixes and separate Linux/Windows
  platform layers.
- Added release licensing and attribution documentation.
